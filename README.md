# Пустошь: Ржавый Предел

Локальная браузерная RPG по мотивам TimeZero (2D, DOM + SVG, без 3D и внешних ассетов).

> **Fan-made проект.** Не аффилировано с TimeZero / TimeZero-Rebirth. Не для публикации или монетизации. Весь визуал процедурный: CSS-градиенты, inline SVG, эмодзи; звук синтезируется через WebAudio. Единственный внешний запрос — шрифты Google Fonts (Inter / JetBrains Mono, есть системный fallback).

## Запуск — 3 команды

```bash
npm i
npm run dev
# открыть http://localhost:3000
```

Если база ещё не создана, создай персонажа на стартовом экране. Данные и переводы проверяются при старте сервера; невалидные `data/*.json` останавливают процесс.

## Что есть в игре

- Персонаж: 1–10 уровень, статы, HP/ОД, очки перков (пока только отображаются), навыки оружия (растут после 10 попаданий).
- Карта мира: 20×20, туман войны, переходы между локациями, случайные встречи и возрождение мобов.
- Бой на гексах 10×10: перемещение, выстрелы, укрытия, позы, прицеливание, перезарядка, аптечки, побег, ИИ мобов; лог боя на RU/EN.
- Экономика: магазины Коваля и шахтёров, покупка/продажа, инфляция и тренды; валюта — армейские жетоны (поле `characters.money` не переименовано).
- NPC: Коваль, Вера, Молчун — диалоги, слухи, просьба о милостыне.
- Лут: 14 мобов, жетоны у всех; люди носят жетоны всегда, крысы — иногда.

## Управление

| Экран | Действия |
|---|---|
| Персонаж | Создание, статы, экипировка, лечение и отдых, навыки оружия, тестовый бой (dev) |
| Карта / локация | Клик по соседней локации — переход; кнопки магазина, NPC, лечения |
| Инвентарь | Экипировка/снятие предметов, использование расходников |
| Магазин | Вкладки «Купить»/«Продать», обновление ассортимента |
| Бой | Клик по мобу → подсветка доступных гексов, затем клик по гексу для выстрела; «Завершить ход» передаёт инициативу мобам |

Deep-link боя: `?battle=<id>` переживает перезагрузку страницы.

## Скрипты

| Команда | Что делает |
|---|---|
| `npm run dev` | Сервер Fastify на `localhost:3000` (tsx watch) |
| `npm run validate-data` | Проверка `data/*.json` схемами Zod + кросс-связи |
| `npm run validate-i18n` | RU/EN — одинаковые наборы ключей |
| `npm test` | Vitest: все тесты этапов 1–10 |
| `npx tsc --noEmit` | Проверка типов сервера и тестов |
| `npm run sim` | Симуляция боёв на реальном движке (по умолчанию 1000; `SIM_BATTLES=10000 npm run sim` для длинного прогона) |

`npm run build` — только `tsc --noEmit`: сборки JS нет, клиент отдаётся как статические ES-модули.

## Баланс (шаг 10a)

- Каждые 10 PER дают +1 гекс эффективной дальности (одинаково для игрока и мобов); снайперское плато считается от эффективной дальности.
- Броня выше 50% поглощения имеет убывающую отдачу: `50 + (base − 50) × 0.5` (80 → 65).
- Лимит лечения в бою: `floor(hpMax × 1.2)`, восстановление `floor(hpMax × 0.2)` за раунд.
- Поражение: HP = 1, деньги × 0.9, возврат в стартовый город.
- `npm run sim` печатает winrate и среднюю длину боя; выход за целевые рамки — предупреждение, а не ошибка.

## Структура

- `server/` — Fastify, REST + WS, SQLite (WAL), игровая логика (`game/battle`, `game/world`, `game/economy`), i18n.
- `client/` — `index.html`, `css/`, `js/`, экраны в `js/screens/`; клиентские hex/LOS — порт серверных модулей.
- `data/` — конфигурация боя, предметы, мобы, NPC, магазины, миры, уровни, i18n (RU/EN).
- `tests/` — тесты этапов 1–10; `server/scripts/sim.ts` — балансовая симуляция.
- `import/` — исходные материалы фанатского клиента; не используется игрой и не коммитится.

Один персонаж в базе (`id = 1`); живой прогресс хранится в `game.db*` и в Git не попадает.
