ЗВУК — WebAudio, синтез, ноль файлов (client/js/audio.js — новый файл):

class AudioSynth {
  constructor() { this.ctx = null; this.enabled = false; this.volume = 0.5; }
  init() { this.ctx = new (window.AudioContext || window.webkitAudioContext)(); this.enabled = true; }
  setVolume(v) { this.volume = v; }
  playHit() { /* короткий square-wave 120Hz + noise burst 0.1s */ }
  playMiss() { /* sine 400Hz → 200Hz за 0.15s */ }
  playCrit() { /* 2 ноты вверх (200→400Hz), 0.2s */ }
  playDeath() { /* низкий noise 60Hz с фильтром, 0.5s */ }
  playHeal() { /* sine 600Hz → 800Hz, 0.3s */ }
  playReload() { /* клик: square 800Hz 0.05s × 2 */ }
  playVictory() { /* 3 ноты: C-E-G (261, 330, 392Hz), 0.6s */ }
  playDefeat() { /* 2 ноты вниз: E-C (330→261Hz), 0.5s */ }
  playStance() { /* клик 600Hz 0.05s */ }
}

- При первом клике пользователя (любого) — audio.init() (браузеры блокируют AudioContext до user gesture).
- Все методы — no-op, если !enabled.
- Громкость: master (0..1), сохранять в localStorage 'audio_volume'.
- Кнопка mute в углу экрана боя (иконка 🔊 / 🔇), состояние в localStorage 'audio_muted'.
- Не использовать файлы. Только OscillatorNode + GainNode + BiquadFilterNode + BufferSource для noise.
