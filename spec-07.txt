2. ЛОГИКА СПАВНА (server/game/world/spawn.ts — новый файл):

function rollEncounter(params: {
  location: Location;
  worldState: WorldState | null;
  config: SpawnConfig;
  rng: () => number;
}): { encounter: false } | { encounter: true; mobIds: string[]; isElite: boolean[] }

  - Если location.type === 'city' → { encounter: false }.
  - Если worldState?.respawnAt и now < respawnAt → { encounter: false }.
  - chance = (location.dangerLevel / 100) × config.encounterChanceMultiplier. Clamp 0..1.
  - if rng() >= chance → { encounter: false }.
  - Выбрать запись из spawnTable взвешенно по weight. Если spawnTable пуст → { encounter: false }.
  - Проверить, что mob.spawnLevelRange пересекается с location.levelRange. Если нет — { encounter: false } (не спавнить).
  - count = mob.tags.includes('pack') ? randInt(config.packMin, config.packMax) : randInt(config.soloMin, config.soloMax).
  - Для каждого из count мобов — ролл элиты: if mob.elite && rng() < config.eliteChance → isElite[i] = true.
  - Вернуть { encounter: true, mobIds: Array(count).fill(mobId), isElite }.

function applyElite(mob: Mob, isElite: boolean): Mob
  - если !isElite → mob (как есть).
  - hp = floor(mob.hp × mob.elite.hpMult)
  - attack.min = floor(mob.attack.min × mob.elite.dmgMult)
  - attack.max = floor(mob.attack.max × mob.elite.dmgMult)
  - вернуть копию mob с изменёнными полями.

function randInt(min, max) — inclusive.
