2. server/api/character.ts — добавить эндпоинты:
   - POST /api/character/rest → 
     * 400 { error: 'not_in_city' }, если location_id не город (type !== 'city' в world.json).

     * inventory qty -= 1; если qty === 0 — удалить строку.
