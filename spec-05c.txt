1. HEX-МАТЕМАТИКА (server/game/battle/hex.ts) — чистые функции:

Тип HexCoord = { q: number; r: number } (axial, pointy-top).

// Координаты
hexToCube(hex): { x, y, z }  // x=q, z=r, y=-x-z
cubeToHex(cube): HexCoord
hexDistance(a, b): number   // манхэттен в кубе: (|dx|+|dy|+|dz|)/2
hexNeighbors(hex): HexCoord[]  // 6 соседей (порядок: E, NE, NW, W, SW, SE)
hexEquals(a, b): boolean
hexAdd(a, b): HexCoord
hexKey(hex): string  // "q,r" для Set/Map

// Пиксели (для SVG, pointy-top)
hexToPixel(hex, size): { x, y }  // size = радиус гекса (расстояние центр→угол)
  - x = size * (sqrt(3) * q + sqrt(3)/2 * r)
  - y = size * (3/2 * r)
pixelToHex({x, y}, size): HexCoord  // обратное преобразование, округление через cube
  - q = (sqrt(3)/3 * x - 1/3 * y) / size
  - r = (2/3 * y) / size
  - округлить через cube-round (стандартный алгоритм)

hexCorners(hex, size): { x, y }[]  // 6 углов для <polygon>

// Соседи в порядке E, NE, NW, W, SW, SE:
// axial directions: [(+1,0), (+1,-1), (0,-1), (-1,0), (-1,+1), (0,+1)]

2. LOS И ДВИЖЕНИЕ (server/game/battle/los.ts) — чистые функции:

hasLineOfSight(params: {
  from: HexCoord;
  to: HexCoord;
  obstacles: Obstacle[];
  mapWidth: number;
  mapHeight: number;
}): boolean
  - Если from === to → true
  - Идти по линии между центрами гексов (алгоритм: cube_lerp + cube_round, стандартный)
  - Если линия пересекает гекс с obstacle.blocksLos === true → false
  - Если линия выходит за границы карты → false (можно стрелять только внутри карты)
  - ВАЖНО: гекс from и to не считаются блокирующими (стрелок и цель не мешают сами себе)
  - ВАЖНО: crate имеет blocksLos: false (за ним можно укрыться, но он не блокирует) — это уже в данных

canMoveTo(params: {
  from: HexCoord;
  to: HexCoord;
  obstacles: Obstacle[];
  occupiedHexes: HexCoord[];  // гексы, занятые другими участниками
  mapWidth: number;
  mapHeight: number;
}): { ok: true } | { ok: false; reason: 'out_of_bounds' | 'blocked' | 'occupied' | 'not_adjacent' }
  - to внутри [0..mapWidth-1] × [0..mapHeight-1] (пересчитать hex в offset coords: col = q + (r - (r&1)) / 2, row = r — для pointy-top odd-r; или проще: проверить, что hexToPixel(to) внутри прямоугольника карты)
  - to не в obstacles с blocksMove: true
  - to не в occupiedHexes
  - hexDistance(from, to) === 1 (только соседний гекс за одно движение; многошаговое — 5d)

reachableHexes(params: {
  from: HexCoord;
  maxSteps: number;
  obstacles: Obstacle[];
  occupiedHexes: HexCoord[];
  mapWidth: number;
  mapHeight: number;
}): Set<string>  // hexKey для всех достижимых гексов в пределах maxSteps (BFS)
  - Для подсветки движения в 5d.

3. SVG-РЕНДЕР (client/js/battle/hex-render.js) — компонент:

hexRender(container, params: {
  map: BattleMap;
  participants: Participant[];
  highlight?: {
    reachable?: Set<string>;       // подсветка достижимых гексов (зелёный)
    los?: Set<string>;            // подсветка гексов с LOS (для стрельбы, синий)
    selected?: HexCoord;          // выбранный гекс (обводка акцентом)
    hover?: HexCoord;             // гекс под курсором (подсветка)
  };
  onHexClick?: (hex: HexCoord) => void;
  onHexHover?: (hex: HexCoord | null) => void;
  hexSize?: number;               // default 28
}) → { destroy(): void; update(params): void }

  - SVG с viewBox, ширина = mapWidth × sqrt(3) × hexSize + padding, высота = mapHeight × 1.5 × hexSize + padding
  - Каждый гекс — <polygon points="..."> с классами:
    * .hex (базовый)
    * .hex.obstacle-wall / .hex.obstacle-rock / .hex.obstacle-tree / .hex.obstacle-crate — заливка по типу
    * .hex.reachable — зелёная подсветка (opacity 0.3)
    * .hex.los — синяя подсветка
    * .hex.selected — обводка 2px акцент
    * .hex.hover — обводка 1px белая
  - Участники — <g> поверх гекса:
    * Игрок — символ "@" (или иконка), класс .participant.player
    * Мобы — первая буква имени (R для грызуна), класс .participant.mob.mob-<mobId> (для разных цветов)
    * HP-бар над участником (тонкий, 20×2px)
    * Позиция (stand/crouch/run/cover) — маленькая иконка в углу гекса (эмодзи: 🧍 / 🧎 / 🏃 / 🛡️)
  - SVG должен масштабироваться (width: 100%; max-width: ...; height: auto)
  - hover/click — через event listeners на <polygon>, данные — data-hex="q,r"
  - destroy() — убрать listeners

6. ТЕСТЫ (Vitest, server/game/battle/__tests__/hex.test.ts и los.test.ts):

hex:
  - hexDistance((0,0), (0,0)) = 0
  - hexDistance((0,0), (1,0)) = 1
  - hexDistance((0,0), (0,1)) = 1
  - hexDistance((0,0), (2,-1)) = 2
  - hexNeighbors((0,0)).length = 6
  - hexToPixel / pixelToHex: round-trip для 100 случайных гексов → тот же гекс (±1)
  - hexToCube((1,2)) → {x:1, y:-3, z:2}, cubeToHex обратно

los:
  - LOS между соседями без препятствий → true
  - LOS через стену (blocksLos: true) → false
  - LOS через crate (blocksLos: false) → true
  - LOS через угол (стена стоит на линии) → false
  - LOS за границу карты → false
  - canMoveTo: сосед, свободен → ok
  - canMoveTo: сосед, стена → blocked
  - canMoveTo: сосед, занят → occupied
  - canMoveTo: не сосед → not_adjacent
  - canMoveTo: за границу → out_of_bounds
  - reachableHexes: 1 шаг, без препятствий → 6 гексов
  - reachableHexes: 2 шага, без препятствий → 18 гексов
  - reachableHexes: 1 шаг, со стеной → 5 гексов

  (набор карт для тестов: пустая 5×5, 5×5 со стеной в центре, 5×5 с углом)
