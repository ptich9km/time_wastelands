ЗАДАЧА 10a — ТОЛЬКО баланс.

1. PER → дальность (data/config/battle.json — добавить секцию "per"):
{
  "per": {
    "rangeBonusPerPoint": 10   // каждые 10 PER = +1 гекс к дальности

}
В hitChance (formulas.ts):
  - Добавить параметр perAttacker (уже есть), weapon, config.
  - effectiveRange = weapon.range + floor(perAttacker / config.per.rangeBonusPerPoint).
  - Использовать effectiveRange вместо weapon.range в distanceMod.
  - ВАЖНО: sniper-кривая тоже использует effectiveRange (плато на 0.7 × effectiveRange).
  - В engine.ts при вызове hitChance передавать perAttacker из participant.stats.per (уже передаётся).
  - ВАЖНО: для мобов per тоже работает (у них есть per). Это честно.

2. Броня после 50% — убывающая отдача (data/config/battle.json — обновить "armor"):
{
  "armor": {
    "formulaAbove6": { "mult50": 50, "coef": 20, "offset": 80 },
    "formulaUpTo6": { "cap": 80, "mult50": 50 },
    "maxAbsorb": 80,
    "diminishingAfter": 50,        // после 50% — убывающая отдача
    "diminishingFactor": 0.5       // k = 0.5: absorb = 50 + (base - 50) * 0.5
  }
}
В armorAbsorb (formulas.ts):
  - Сначала вычислить base_absorb по текущей формуле (до 80).
  - Если base_absorb <= diminishingAfter (50) → вернуть base_absorb.
  - Иначе → return diminishingAfter + (base_absorb - diminishingAfter) × diminishingFactor.
  - Clamp 0..maxAbsorb.
  - ПРИМЕР: base = 80 → 50 + (80-50)×0.5 = 65. Было 80, стало 65. Слабее.
  - ПРИМЕР: base = 50 → 50. Без изменений.
  - ПРИМЕР: base = 30 → 30. Без изменений.
  - ВАЖНО: формула из вики «после 50% — гипербола», но мы делаем линейную убывающую отдачу — проще, тестируется, даёт контроль. Если хочешь точную гиперболу — сложнее, не рекомендую для MVP.
