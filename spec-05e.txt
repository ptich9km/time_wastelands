2. AI-МОДУЛЬ (server/game/battle/ai.ts — новый файл):

// Чистые функции, без side effects, инъекция RNG.
// Каждая функция возвращает решение, а применение — в runEnemyTurn.

function decideMobAction(params: {
  mob: Participant;
  state: BattleState;
  items: Item[];
  config: BattleConfig;
  rng: () => number;
}): { type: 'move'; to: HexCoord }
  | { type: 'shoot'; targetId: string; zone: Zone }
  | { type: 'flee' }
  | { type: 'wait' }   // закончить ход моба

  // Логика:
  // 1. Если mob.ai (по mobId из mobs.json) — coward и hp < max × fleeAtHpPct / 100:
  //    - если ap >= fleeApThreshold → { type: 'flee' }
  //    - иначе → искать укрытие (двигаться к ближайшему гексу с cover-возможностью)
  // 2. Иначе (aggressive или coward не в бегстве):
  //    - найти ближайшего живого врага (player). Если нет — 'wait'
  //    - distance = hexDistance(mob.hex, player.hex)
  //    - if distance <= weapon.range && hasLineOfSight(mob.hex, player.hex, obstacles):
  //        → { type: 'shoot', targetId: player.id, zone: preferZone }
  //      (если ap хватает на shootXxx; если нет — 'wait')
  //    - else (нужно двигаться):
  //        - если distance <= weapon.range, но нет LOS:
  //            - найти соседний гекс, откуда есть LOS, и подвинуться туда (1 шаг)
  //            - если нет — 'wait'
  //        - else:
  //            - reachable = reachableHexes({ from: mob.hex, maxSteps: floor(ap / moveCost), ... })
  //            - выбрать гекс из reachable, который минимизирует расстояние до player
  //              (при равенстве — предпочесть гекс с LOS к player, если distance <= weapon.range)
  //            - если некуда — 'wait'
  // 3. Если ap < moveCost — 'wait'
  //
  // ВАЖНО: mobile mob с range 1 (ближник) — подход + атака в упор.
  // Mobile mob с range 3–4 (стрелок) — подход до range, потом стрельба.

function findBestMoveHex(params: {
  from: HexCoord;
  targetHex: HexCoord;          // куда хотим приблизиться
  reachable: Set<string>;
  obstacles: Obstacle[];
  occupiedHexes: HexCoord[];
  weaponRange: number;
  needsLos: boolean;            // true, если моб — стрелок (range > 1)
}): HexCoord | null
  - Перебрать reachable, для каждого посчитать:
    * distanceToTarget
    * hasLosToTarget
  - Предпочесть: сначала те, где hasLosToTarget && distanceToTarget <= weaponRange, потом где hasLosToTarget, потом где distanceToTarget <= weaponRange, потом остальные.
  - В каждой группе — минимальное distanceToTarget. При равенстве — стабильный порядок (по hexKey).
  - Вернуть null, если reachable пуст.

  state: BattleState;
  config: BattleConfig;
  items: Item[];
  mobs: Mob[];            // gameData.mobs
  rng: () => number;
  lang: 'ru'|'en';

  //       - списать ap по moveCost/attackCost
  //       - записать лог (actor = mob.id)
  //       - если игрок мёртв — status = 'defeat', phase = 'finished', result = 'defeat' → break
  //       - если все мобы мертвы — status = 'victory' (но в 5e мобы не умирают, только игрок)
  //    c. Ограничить: максимум 5 действий за ход одного моба (защита от бесконечного цикла).
  // 3. После всех мобов:
  //    - round += 1
  //    - healLimit.current = min(healLimit.max, healLimit.current + healLimit.regenPerRound)
  //    - для всех участников: восстановить ap = apMax (игрок — при следующем его ходе, но проще — сразу)
  //    - для всех effects: ttlRounds -= 1, удалить с ttl <= 0
  //    - phase = 'player_turn', currentActorId = 'player'
  //    - если status === 'defeat' → phase = 'finished'
  //    - лог: "--- Раунд {round} ---"
  // 4. Вернуть { newState, logEntries }

  // ВАЖНО: apMax мобов. В 5a мы ставили ap = 4 (заглушка). В 5e — заменить на mob.moveAp + mob.attackAp (из mobs.json). Для pipe_rat: 4 + 8 = 12. Моб может сделать: 1 атаку (8) + 1 шаг (4) = 12. Или 3 шага (12) без атаки.
  //   Если mob.moveAp/attackAp нет в items.json — дефолты 4/8.

  // ВАЖНО: мобы не должны «стрелять» в мёртвых (hp <= 0). Если все враги мертвы — 'wait'.
  // ВАЖНО: для стрелков (range > 1) — нужен LOS. Для ближников (range === 1) — LOS не нужен (бьют в упор).
