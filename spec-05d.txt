Валидация общая:
  - state.status !== 'active' → battle_finished
  - state.currentActorId !== 'player' → not_your_turn
  - if action.type === 'endTurn' — разрешено всегда (даже с ОД)

Действие 'move' { to }:
  - Проверить canMoveTo({ from: player.hex, to, obstacles: state.map.obstacles, occupiedHexes: [все участники кроме player], mapWidth, mapHeight })
    * not_adjacent / occupied / out_of_bounds / blocked — вернуть соответствующий error
  - apCost = position === 'run' ? moveRun : (position === 'crouch' ? moveCrouch : moveStand)
  - Если player.ap < apCost → not_enough_ap
  - player.ap -= apCost; player.hex = to
  - log: type 'info', текст: "Вы перемещаетесь на гекс (q,r)" / "You move to hex (q,r)"

Действие 'shoot' { targetId, zone }:
  - Найти цель в participants по id. Не игрок → invalid_target. Мёртвая (hp <= 0) → invalid_target.
  - У игрока должно быть оружие (weaponId !== null) → no_weapon
  - Оружие существует в items → unknown_item
  - Если оружие имеет charges и они 0 → no_ammo (нужна перезарядка)
  - distance = hexDistance(player.hex, target.hex)
  - Если distance > weapon.range → out_of_range (можно стрелять только в пределах range; вне range — только урон режется, но в 5d запрещаем выстрел за range для простоты; в 5e/6 можно разрешить)
  - hasLineOfSight(player.hex, target.hex, obstacles) → false → no_line_of_sight
  - apCost = apCosts['shoot' + weaponCategory]
  - Если player.ap < apCost → not_enough_ap
  - Применить формулы:
    * hitParams = hitChance({ perAttacker: player.stats.per, agiTarget: target.stats.agi, zone, distanceHexes: distance, weapon: { range, spread, sniper }, positionAttacker: player.position, positionTarget: target.position, coverTarget: target.position === 'cover', config: config.hit })
    * roll = rng() * 100
    * if roll >= hitParams.chance → промах:
        log: type 'miss', текст: t('battle.miss', lang, { target: mobName })
        НЕ списывать патрон? — списывать (выстрел был)
    * else:
        baseDmg = rollDamage({ weaponDamage: weapon.damage, ammoBonus: 0, rng })
        // crit
        crit = rollCrit({ intel: player.stats.intel, config: config.damage, rng })
        if crit → baseDmg = applyCrit(baseDmg, config.damage)
        // armor
        const armorId = target.equipment.armor[zone === 'head' ? 'head' : zone === 'torso' ? 'torso' : zone === 'arms' ? 'arms' : 'legs']
        const armorItem = items.find(i => i.id === armorId)
        const armorValue = armorItem?.armor?.[zone] ?? 0
        const absorb = armorAbsorb({ armorValue, weaponLevel: weapon.level, config: config.armor })
        // penetration
        const penetrated = rollPenetration({ pen: weapon.pen, rng })
        const finalDmg = damageWithPenetration({ baseDamage: baseDmg, absorb, penetrated, config: config.penetration })
        target.hp = max(0, target.hp - finalDmg)
        log: type crit ? 'crit' : 'hit', текст с { target, dmg, zone }
        Если target.hp === 0 → type 'death' дополнительно, status = 'victory' если все мобы мертвы
    * player.ap -= apCost
    * Если weapon.charges !== undefined → weapon.charges -= 1 (это в state; или в inventory? — в state, чтобы не мутировать БД во время боя; синхронизация — после боя)
  - ВАЖНО: списание патронов — в Participant.equipment.weaponCharges (добавить поле в ParticipantSchema: weaponCharges?: number). После боя — синхронизировать с inventory (это этап 6).
