3. СХЕМА БД (server/db/schema.sql — CREATE TABLE IF NOT EXISTS):
   shop_state (
     shop_id TEXT NOT NULL,
     item_id TEXT NOT NULL,
     stock INTEGER NOT NULL DEFAULT 0 CHECK (stock >= 0),
     inflation REAL NOT NULL DEFAULT 0,   -- 0..N, накапливается от покупок
     trend INTEGER NOT NULL DEFAULT 0,    -- 1 = "в тренде дня" (продажа 70%), 0 = обычная (50%)
     restocked_at TEXT NOT NULL DEFAULT (datetime('now')),
     PRIMARY KEY (shop_id, item_id)
   )
   Индекс: (shop_id).
   -- trend и restocked_at обновляются раз в игровые сутки (15 минут реального времени).

4. РЕПОЗИТОРИЙ (server/db/shop-repo.ts):
   - getShopState(db, shopId) → [{itemId, stock, inflation, trend, restockedAt}]
   - upsertShopState(db, shopId, itemId, {stock, inflation, trend, restockedAt})
   - getShop(db, shopId) → Shop из gameData.shops.shops
   - restockIfNeeded(db, shopId, now) → если restockedAt старше 15 минут реального времени — пересчитать сток (baseQty), сбросить inflation = 0, выбрать 1 случайный предмет как trend = 1 (остальные 0), restockedAt = now.
   - getPrice(basePrice, shopMultiplier, inflation) → round(basePrice × shopMultiplier × (1 + inflation / 100))
   - increaseInflation(db, shopId, itemId, amount=0.5) → inflation += 0.5 (clamp 0..50)
   - getSellPrice(basePrice, isTrend) → round(basePrice × (isTrend ? 0.7 : 0.5))

5. ЛОГИКА (server/game/economy/shop.ts):
   - canBuy(character, item, shopState, price) → { ok: true } | { ok: false, reason: 'not_enough_money' | 'out_of_stock' | 'requirements_not_met' }
   - buyItem(db, characterId, shopId, itemId) →
     * restockIfNeeded
     * получить shopState
     * если stock <= 0 → 400 out_of_stock
     * price = getPrice
     * если character.money < price → 400 not_enough_money
     * проверить requirements (level, str, agi, int, end, per, intel) — если не выполнены → 400 requirements_not_met
     * character.money -= price
     * inventory.addItem(itemId, 1)
     * shopState.stock -= 1; inflation += 0.5
     * 200 { character, inventory, shopState }
   - sellItem(db, characterId, shopId, inventoryId) →
     * получить строку inventory
     * item = items[inventoryId.itemId]
     * если item.type === 'misc' и price < 5 → всё равно можно продать (за 1–2 гильзы)
     * isTrend = shopState.trend === 1 для этого itemId
     * price = getSellPrice(item.price, isTrend)
     * inventory qty -= 1; если qty === 0 — удалить
     * character.money += price
     * 200 { character, inventory, price }

6. NPC ЛОГИКА (server/game/economy/npc.ts):
   - getNpcDialog(npc, lang) → { line: string, rumor?: string } — случайная line из dialogueKeys, случайный rumor из rumorKeys (опционально).
   - Милостыня: beggar(db, characterId) →
     * Проверить: money < 20 И hp_current < 30% от hp_max.
     * Проверить meta: last_beggar_at — если < 24 часов назад → 400 already_begged.
     * money += 10, hp_current = min(hp_max, hp_current + 20).
     * meta.last_beggar_at = now.
     * 200 { character, received: {money: 10, hp: 20} }.

7. REST API (server/api/shop.ts — новый файл):
   - GET /api/shop/:shopId → 200 { shop: { id, nameKey, locationId, items: [{itemId, nameKey, price, stock, trend, requirements, rarity, icon}] } }
     * 404 если shopId нет.
     * 400 если персонаж не в этом городе (location_id !== shop.locationId).
   - POST /api/shop/:shopId/buy → body { itemId, qty? = 1 }
     * 200 { character, inventory, shop }
     * 400 not_enough_money | out_of_stock | requirements_not_met
   - POST /api/shop/:shopId/sell → body { inventoryId }
     * 200 { character, inventory, shop, price }
     * 400 not_found | not_sellable (нельзя продать экипированное)
   - server/api/npc.ts — новый файл:
     * GET /api/npc/:npcId → 200 { npc: { id, nameKey, role, line, rumor? } }
     * POST /api/npc/:npcId/beggar → 200 { character, received } | 400 not_eligible | already_begged
   - Регистрация в index.ts.
