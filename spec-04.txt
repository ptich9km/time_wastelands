1. НОВАЯ СХЕМА ПРЕДМЕТОВ (server/schemas/items.ts):

Базовые поля (все типы):
- id: IdSchema
- nameKey: I18nKey
- descriptionKey: I18nKey
- icon: эмодзи (1–4 символа)
- price: int >= 1
- weight: number >= 0
- rarity: common | uncommon | rare | epic
- requirements: { level?, str?, agi?, int?, end?, per?, intel? } — все опциональные, int >= 1
- durability: int >= 1 (default 100)
- tags: string[]

Оружие (type: "weapon"):
- slot: "weapon"
- weaponCategory: "light" | "medium" | "heavy" | "sniper" | "melee"  — 5 категорий в MVP (без thrown/energy/bio)
- level: int >= 1 — уровень оружия для формулы брони
- damage: { min, max } — int >= 0, max >= min
- range: int >= 1 — гексы
- spread: int 0–100 — % попадания на макс. дальности
- sniper: boolean (default false) — только для sniper-категории, если true — спец-система (10% в упор → spread/100 на 70% дальности → плато)
- apCost: int >= 1 — ОД за выстрел
- reloadAp: int >= 1 — ОД за перезарядку
- pen: int 0–100 — % бронебойности
- charges: int >= 1 — патронов в магазине
- ammoType: "light" | "medium" | "heavy" — обязателен, если charges задан
- УБРАТЬ: accuracy, speed, weaponType (старое)
- НОВОЕ: две руки? — в MVP не нужно, не добавляй

Броня (type: "armor"):
- slot: "head" | "torso" | "jacket" | "legs" | "boots"
- level: int >= 1 — уровень брони (для формулы поглощения)
- armor: { head, torso, arms, legs } — int >= 0 (значение, не %)
- убрать accuracy/speed (их и не было)

Расходник (type: "consumable"):
- effect: { heal?, cure?, restoreCharges?, durationRounds? }
- без изменений

Патроны (type: "ammo"):
- ammoType: "light" | "medium" | "heavy"
- charges: int >= 1 — сколько патронов в одной единице
- damageBonus: int >= 0 (default 0) — прибавка к урону оружия

Разное (type: "misc"):
- без изменений

ItemsFileSchema — superRefine:
- дубликаты id
- для каждого weapon.ammoType есть ammo-предмет этого типа
- для каждого weapon.level >= 1 и range >= 1 и apCost >= 1
- для каждого weapon.sniper: если true, то weaponCategory === "sniper"; если weaponCategory === "sniper", то sniper === true
- для каждого armor.level >= 1

2. НОВАЯ СХЕМА МОБОВ (server/schemas/mobs.ts):

- id, nameKey, descriptionKey?, level, hp
- stats: { str, agi, int, end, per, intel } — все int >= 1, но per и intel могут быть 0 (в отличие от v1.1)
- attack: { min, max, pen, range } — pen 0–100, range >= 1, max >= min
- ai: "aggressive" | "coward"  — в MVP только эти два (tactical/berserk — v0.2)
- moveAp: int >= 1 (default 4)
- attackAp: int >= 1 (default 8)
- xp: int >= 0 — оставляем поле, но в v2.0 XP считается по HP моба (см. ниже), поле xp не используется. Оставь с default 0 для совместимости.
- loot: { guaranteed?: LootEntry, rare: LootEntry[] }
- spawnLevelRange: [min, max], max >= min
- elite?: { hpMult, dmgMult, xpMult, rareChanceBonus }
- tags: string[]

MobsFileSchema superRefine:
- дубликаты id
- elite.hpMult > 0, dmgMult > 0, xpMult > 0, rareChanceBonus 0–1
- attack.range >= 1
